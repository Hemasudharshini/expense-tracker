# 💰 Expense Tracker

A modern and responsive personal finance dashboard built using HTML, CSS, Bootstrap 5, and JavaScript.

The application allows users to manage income and expenses, calculate their balance, search transactions, and store data directly in the browser using LocalStorage.

## ✨ Features

- Add income and expenses
- Automatic income calculation
- Automatic expense calculation
- Automatic balance calculation
- Delete transactions
- Search transactions
- Transaction count
- Form validation
- LocalStorage persistence
- Responsive design
- Modern dashboard UI
- Interactive hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- LocalStorage
